# 写作技法库与风格迁移守则

本文件解决两件事：把风格档案变成**可执行的写作规则**，以及按量化偏离**有章法地改写**。给建议时先查这里，不要只说「多用短句」「注意语感」。

## 一、风格的六个可迁移维度

风格不是「用了哪些词」，而是下面六层共同形成的阅读体感。创作时逐层对齐，缺一层就会「像但不像」。

### 1. 叙述视角与距离
- 第一人称限知：所有信息必须经过「我」的感官与判断，不能写我看不到的心理；`first_person_per_1k` 高。
- 第三人称限知：贴住一个人物，用「他」但只写他知道的；与全知的区别在于**是否评论其他人物内心**。
- 全知/评书式：可自由评论、预告、插叙；常配「却说」「看官」类套语，`classical_per_1k` 高。
- 距离调节：靠近 = 感官细节、短句、当下时态；拉远 = 概述、时间跳跃、概括句。
- **视角漂移是仿写最常见失败**：写着写着突然写出「她心里其实……」而原文从不进他人内心。

### 2. 节奏
- 句长分布比平均句长更重要。长句铺陈 + 极短句收束，是很多作者的招牌（`std_sentence_chars` 高）。
- 场景用慢节奏（动作拆成短句、感官细节、对话），过渡用概述（一段跨过数日）。
- 段落长度控制呼吸：一句一段 = 停顿与强调；大段 = 沉浸与连续。
- 标点就是节奏记号：破折号打断、省略号留白、逗号绵延、句号切断。

### 3. 用词轴
- 书面 ↔ 口语：`classical_per_1k` 与 `colloquial_per_1k` 的两端。同一作者在不同人物对话里可能切换，叙述与对话要分开处理。
- 单双音节：单字动词（「掀」「掷」「顿」）硬朗；双音节（「掀开」「掷出」「停顿」）舒缓。
- 动词驱动 vs 形容词驱动：前者靠动作推进，后者靠修饰堆叠。`verb_ratio` 与 `adj_ratio` 给出方向。
- 时代语感：旧白话套语、翻译腔长定语、网络口语，各自有词表。用词要与题材年代自洽。
- 高频核心词是「音色的底噪」，但**不要照抄**：见第六节。

### 4. 描写系统
- 感官偏好：只看视觉 vs 听觉/嗅觉/触觉并用。仿写时按 `sensory_profile` 的比例补细节，而不是随手加视觉描写。
- 意象域：有的作者总用天气与器物，有的总用身体与病理，有的用市井食物。从 `top_nouns` 里归纳，创作时让喻体和物象落在同一域。
- 比喻：先判断是明喻（带仿佛/宛如）还是暗喻、是否用喻、喻体来自自然还是日常器物。`simile_per_1k` 只测明喻标记。
- 色彩与光影：低色彩词 + 多光影词 = 靠明暗造型；高色彩词 = 直接点色。

### 5. 对话写法
- 对话占比与是否独立成段（`dialogue_char_ratio`、`dialogue_paragraph_ratio`）。
- 对话标签：完全省略 / 「他说」/ 带动作（「他把碗一推」）/ 带神态。原文偏哪类就固定用哪类。
- 潜台词：人物是否直说心意。极简风格常让对话答非所问，靠动作补情绪。
- 口吻区分：不同人物是否有语体差异。若原文人人同一种腔调，仿写也不要突然个性化。

### 6. 结构习惯
- 开头：从场景切入 / 从概述切入 / 从一句判断切入。
- 章节收束：悬念钩 / 情绪落点 / 景物定格。
- 伏笔与回照、时间线是否打乱、是否用插叙。
- 这些脚本测不到，必须从原文读出来写进档案。

## 二、把档案变成 DO / DON'T 规则

规则必须**可判定、可违反**，否则等于没写。坏例子：「语言简洁有韵味」。好例子：

| 维度 | DO | DON'T |
| --- | --- | --- |
| 句法 | 叙述句控制在 25–40 字，用逗号分三层；每三段插入一句 8 字以内的短句收束 | 不写连续三个以上 10 字以内短句（对话除外） |
| 用词 | 优先单字动词；四字格每段最多一处 | 不用网络流行语、不用「仿佛/宛如」以外的比喻套语 |
| 描写 | 每段至少一处非视觉感官（气味、温度、声音） | 不直接写人物情绪词（「他很悲伤」），改用物象与动作 |
| 对话 | 每轮独立成段，标签用动作代替「他说」 | 不让对话超过全篇 15% |
| 视角 | 全程贴住单一人物，只写其可感知信息 | 不写他人内心、不做全知评论 |

写风格卡时，每条规则后面附一句「为什么」和一条原文短引（≤20 字），方便创作时快速回忆体感。

## 三、创作流程

1. **先确认任务参数**：题材、梗概、人物、字数、人称、章节数、要不要续写、有没有必须出现的意象。用户没给的按档案默认，并在交付时说明假设。
2. **列场景清单再落笔**：把篇幅拆成 3–8 个场景，标注每个场景的节奏（慢/快）、主导感官、是否含对话。这能防止「前半段像、后半段跑偏」。
3. **按风格卡写初稿**：只盯 DO/DON'T，不要边写边模仿原句。人物、情节、地点、专有名词必须全新。
4. **落笔自检三问**：这句的视角对吗？这个比喻的喻体属于原文的意象域吗？这段的句长分布和档案差得远吗？
5. **输出标注**：文件头写明「风格仿作练习 · 学习对象：{作者/书名}」，避免被误认为原文或原作者作品。

## 四、按量化偏离改写（本 Skill 的闭环）

1. 跑 `compare`，读 `top_deviations` 与 `next_actions`。
2. **只改优先级最高的 3–5 项**，不要一次追所有指标；指标之间会互相牵动（加长句会同时改变句长、逗号密度、长句比例）。
3. 按 `hint` 做结构性修改，而不是塞关键词：
   - 句长偏短 → 合并句子、加状语与定语，不是往句尾硬加形容词。
   - 对话偏多 → 把一段对话转成概述或动作描写，不是删掉半句台词。
   - 文言味不足 → 调整叙述层的语体，不是往人物对话里塞「遂」「乃」。
   - 感官密度不足 → 补与场景自洽的听觉/嗅觉细节，不是罗列气味清单。
4. 改写后**复测一次**，最多两轮。两轮后仍偏离的项，如实写进交付说明（例如「第一人称密度按情节需要保留」），不要为凑分把文章写坏。
5. `overall_similarity` 只是参考：≥0.82 为高度贴合，0.68–0.82 为可用，<0.68 需说明原因。**绝不为提高分数复制原文高频词**；`word_overlap.coverage > 0.55` 时应反过来警惕。

## 五、常见问题

| 症状 | 原因 | 修正 |
| --- | --- | --- |
| 读起来像「把特征词串起来」 | 只对齐了词汇层，没对齐节奏与视角 | 回到第一、二节，重写场景清单 |
| 前半段像后半段崩 | 没有分段控制节奏 | 每写完 1/3 回读风格卡一次 |
| 视角突然全知 | 情节需要解释人物动机 | 用动作、对话、物象暗示，不直接写内心 |
| 比喻别扭 | 喻体不在原文意象域 | 从 `top_nouns` 归纳意象域后重选喻体 |
| 人物说话都一个腔 | 原文其实有口吻差异，或反过来被强行个性化 | 回原文数一下对话标签与语气词分布 |
| 指标全对但不好看 | 过度优化数值，牺牲了叙事逻辑 | 以可读性优先，保留偏离并说明 |

## 六、版权与伦理边界（必须遵守）

- 提取与学习的是**统计特征与写作技法**，不是原文表达。不复制原句、独特比喻、人物姓名、专有名词、情节桥段或标志性台词。
- 不产出可被认定为「原文续写／改写／代笔」的内容。用户明确要求续写时，只作为私人练习处理，并在文件头标注，不宣称是原作者作品。
- 不使用「某某亲笔」「原作风格官方续作」等误导性表述；对外分享时注明是风格仿写练习。
- 用户提供的文本**只在本地处理**，不上传任何在线服务、不写进外部请求、不写进日志。分析结束后原始样本保留在用户自己的档案目录，不随 Skill 分发。
- 不复现样本的正文到报告里；原文例证只作 ≤20 字短引，且仅用于说明技法。
- 若用户要求模仿在世作者并用于商业发布，提醒其自行核对署名与授权要求；本 Skill 不提供法律判断。

## 七、风格卡的使用

`style-card.md` 是档案的压缩版（建议 ≤600 字），**创作时只读它**，避免整份档案占满上下文。需要核对具体数据或例句时再打开 `style-profile.md`。卡片应包含：六维度各一行 + DO 清单 + DON'T 清单 + 一句口诀 + 禁区提醒。
