# 文体指标解读指南

把 `profile.json` 里的数字翻译成可写进风格档案的判断。所有阈值都是**中文小说的经验参考值**，不是绝对标准。指标测的是「表层语言习惯」，不等于作者的想象力、结构能力或人物塑造。

## 三条铁律

1. **先看 `warnings` 和 `meta`。** 样本过短、对话过重、非中文混入、降级分词，都会让数据失真。
2. **单一指标不下结论。** 每个判断至少两个指标互相印证，并且必须回到原文读几段确认。
3. **同体裁才可比。** 武侠、言情、悬疑、网文、严肃文学的句长基线差异极大；拿网文指标去套散文体小说没有意义。所有「偏高/偏低」都是相对目标档案而言。

## 字段地图

| 分组 | 内容 |
| --- | --- |
| `meta` | 字数、句数、段数、词数、分词器、样本文件路径 |
| `syntax` | 句长分布、段长、逗号密度、单句成段比例 |
| `punctuation` | 各类标点每千字频次 |
| `vocabulary` | 词汇丰富度、词长、四字格、语体标记、感官/比喻/色彩密度、词性占比 |
| `narration` | 对话占比、人称密度、主叙述人称、章节结构 |
| `signature` | 高频实词、动词/名词/形容词/副词 top 榜、句首句尾、感官分布 |
| `warnings` | 样本与测量限制 |

## 句法与节奏

| 指标 | 低 | 高 | 解读要点 |
| --- | --- | --- | --- |
| `avg_sentence_chars` | ≤12 短促、断裂、动作感强 | 12–24 均衡；25–40 绵长铺陈；>40 极长句 | 中文小说最有效的风格指纹之一。必须结合 `dialogue_char_ratio` 看 |
| `std_sentence_chars` | <8 节奏均匀 | >18 长短落差大 | 高落差常出现在「长描写 + 极短收束」的写法 |
| `short_sentence_ratio_le10` | <0.15 少用短句 | >0.45 短句驱动 | 短句密集也可能是大量对话造成的假象 |
| `long_sentence_ratio_ge36` | <0.05 少铺陈 | >0.25 一逗到底 | 与 `comma_per_sentence` 互相印证 |
| `avg_paragraph_chars` | ≤25 对话体、镜头切得快 | 60–150 叙述体、段落厚实 | 网文常偏短，纯文学常偏长 |
| `single_sentence_paragraph_ratio` | 低=段落成块 | 高=一句一段、留白多 | 与悬疑、冷硬派、诗性叙述相关 |
| `comma_per_sentence` | <0.8 句子干净利落 | >2.0 层层附加、气息绵长 | 高值 + 长句 = 典型的「一逗到底」 |

**标点**：`ellipsis_per_1k` 高 → 迟疑、留白、未完成感；`dash_per_1k` 高 → 补充、打断、思维跳接；`exclamation_per_1k` 高 → 情绪外露；`question_per_1k` 高 → 追问、内心不确定。四个都低 + 句号占绝对多数 → 克制、冷叙述。

## 词汇与语体

| 指标 | 解读 |
| --- | --- |
| `mattr_1000` | 滑动窗口型例比（每千字）。0.45–0.55 复用核心词、语流稳；0.6+ 换词勤、词汇密。样本短时该值会虚高 |
| `avg_word_len` / `single_char_word_ratio` | 单字词多 → 古简、硬朗、动作感；双音节多 → 现代、舒缓 |
| `four_char_per_1k` / `idiom_per_1k` | 四字格与成语密度高 → 整齐、书面、旧白话或评书味；低 → 口语、散文化 |
| `classical_per_1k` | 方才/但见/不曾/遂/须臾 等旧白话与文言标记；高 → 时代感、评书/古典味 |
| `colloquial_per_1k` | 吧/嘛/呗/啥/咋 等口语标记；高 → 贴近口语、现代、人物口吻鲜活 |
| `simile_per_1k` | 仿佛/宛如/如同 类明喻。**只测标记词，不测隐喻**，需回原文看喻体来源 |
| `sensory_per_1k` + `signature.sensory_profile` | 看感官偏好：只重视觉 vs 听觉/嗅觉/触觉并用。嗅觉触觉突出常是作者个人标记 |
| `color_per_1k` | 色彩词直白程度；低而光影词多 → 靠明暗而非颜色词造型 |
| `verb_ratio` vs `adj_ratio` | 动词驱动（推进、动作）vs 形容词驱动（铺陈、氛围）。这是「文风硬/软」的关键轴 |
| `noun_ratio` | 高 → 物象密集、白描；配合 `top_nouns` 看意象域 |
| `pronoun_ratio` | 代词多 → 承接紧密、视角贴近；少 → 靠姓名/名词复现，距离感强 |

`signature.top_verbs` / `top_adjectives` / `top_nouns` 是**用词习惯**的直接证据，但必须人工筛：把人名、地名、题材专有词（如「灵力」「案子」「江湖」）与真正的风格词分开。高频题材词只说明写的是什么，不说明怎么写。

`sentence_openers` / `sentence_enders` 能暴露句法口头禅（例如总用「他」「于是」「只见」起句，或爱用「罢了」「似的」收句）。

## 叙事层

| 指标 | 参考 |
| --- | --- |
| `dialogue_char_ratio` | <0.10 叙述/描写主导；0.20–0.40 均衡；>0.50 对话驱动（此时句长指标被对话主导） |
| `dialogue_paragraph_ratio` | 高 → 每轮对话独立成段，接近剧本式；低 → 对话嵌在叙述段落里 |
| `dominant_person` | 只是**代词统计**，不等于叙述视角。第一人称小说里「他/她」也可能很多；必须回原文确认限知/全知、是否换视角 |
| `chapter_count` / `avg_chapter_chars` | 章节体量与切分密度；结合开头/结尾读法判断结构习惯 |

脚本**测不到**的关键项，必须由 Agent 读原文补上：叙述视角与视角切换、场景(scene)与概述(summary)的配比、时间线处理、悬念与伏笔、人物口吻区分、母题与意象系统、开头与收束的套路、幽默或反讽的质地。

## 常见误判

| 现象 | 容易误判成 | 应先检查 |
| --- | --- | --- |
| 平均句长极短 | 作者偏爱短句 | 对话占比是否 >0.4；剧本式对话会大幅拉低均值 |
| 文言标记高 | 古文写作 | 是否只是武侠/历史题材的套语；看 `colloquial_per_1k` 是否同时高 |
| 词汇丰富度高 | 文采好 | 样本是否过短（<3000 字时 MATTR 虚高）、是否混入章节标题/人名表 |
| 形容词占比低 | 白描风格 | 是否分词把形容词切成了名词；看 `top_content_words` 复核 |
| 第三人称代词多 | 全知视角 | 回原文看是否其实限知于单一人物 |
| 两份档案差异巨大 | 两位作者风格迥异 | 是否跨体裁、跨时代、或一份是纯对话节选 |
| 仿稿词汇重合度高 | 模仿成功 | 可能只是照抄高频词，节奏和视角仍然不对 |

## 从数据到画像：推理示例

**例 A**：`avg_sentence_chars=6.1, std=4.2, short_ratio=0.82, avg_paragraph_chars=8.3, dialogue_ratio=0.27, colloquial/1k=23.1, classical/1k=0, simile/1k=0, dominant=first`。
→ 极短句、一句一段、口语标记密集、零比喻、第一人称。判断：冷硬/极简的城市口语叙述，靠动作与对话推进，几乎不做环境铺陈。写这类风格时**最忌**加形容词和比喻。

**例 B**：`avg_sentence_chars=33.0, std=26.4, long_ratio=0.37, avg_paragraph_chars=61.9, dialogue_ratio=0.007, classical/1k=8.1, simile/1k=5.0, sensory/1k=5.0, dominant=third`。
→ 长句与极短句交替、段落厚重、几乎无对话、旧白话标记与明喻并用、感官铺陈。判断：抒情性第三人称叙述，以景写情，节奏靠长短落差而非情节推动。写这类风格时**最忌**用大量短对话把气息打断。

**例 C**：`warnings` 含「Dialogue exceeds 55%」且 `avg_sentence_chars=9.2`。
→ 先按对话体解释句长，不要写「作者习惯短句」；若样本是节选，建议补一段纯叙述章节重测。

## 报告措辞规范

- 写「这段样本里」「倾向于」「在 X 与 Y 两个指标上」，不写「该作者天生」。
- 每条判断给出：现象 → 数据依据 → 原文短引（≤20 字）→ 对创作的可操作含义。
- 明确区分「 measurable 的表层特征」与「需要读原文才得出的技法判断」。
- 结尾列出本次测量的置信度与限制。
